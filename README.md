# Mission entretien chez Mme Martin

Jeu pédagogique individuel consacré au choix et à l’utilisation des produits d’entretien, à la sécurité, aux méthodes de nettoyage et aux écogestes.

## Parcours

1. Observer la situation chez Mme Martin
2. Associer les produits à leur fonction
3. Retrouver les mots de sécurité
4. Reconstituer le cercle de Sinner
5. Remettre les gestes dans l’ordre
6. Associer les pictogrammes de danger
7. Choisir les écogestes dans le logement
8. Réaliser la mission finale et télécharger le bilan PDF

## Utilisation individuelle

Le site ne possède aucun serveur de données. Chaque profil, réponse, score et bilan reste dans le navigateur utilisé. Plusieurs profils peuvent coexister sur un même appareil. Les apprenants qui ouvrent le même lien sur des appareils différents ne partagent aucune progression.

## Publication GitHub Pages

Le workflow inclus publie automatiquement le site lors d’un envoi sur la branche `main`.

1. Créer un dépôt GitHub et y envoyer ce dossier.
2. Dans **Settings > Pages**, choisir **GitHub Actions** comme source.
3. Ouvrir l’onglet **Actions** pour suivre la première publication.
